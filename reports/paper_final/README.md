# Paper-final evaluation layer

Everything the paper needs, added on branch `paper-final-eval-2026` without moving or rewriting
any earlier report. **Start with `PAPER_RESULT_SUMMARY.md`.**

| file | what it answers |
|---|---|
| `PAPER_RESULT_SUMMARY.md` | the 20 paper questions, with value / N / CI / comparison / artifact for each |
| `AUDIT.md` | what existed, what was paper-ready, what was unfair or unsupported before this round |
| `EVALUATION_PROTOCOL.md` | the frozen protocol (split, normalization, metric definitions, decoding, statistics) |
| `MAIN_RESULTS.md` | Qwen-ABC vs MuPT vs MIDI-LLM on the 225 test songs |
| `FAIR_DECODING.md` | single sample vs selector@4 vs oracle@4/8 |
| `ESS_ABLATION.md` | the Explicit Structural State ablation (training/representation only) |
| `LONG_RANGE_ANALYSIS.md` | failure rates by normalized song position |
| `INTERVENTIONAL_CONTROLLABILITY.md` | one-control interventions vs the reseed noise floor, incl. lyrics→melody |
| `OOD_GENERALIZATION.md` | in-distribution vs compositional vs extrapolative control requests |
| `MUSICALITY_VS_CONTROL.md` | musical fluency statistics next to control adherence |
| `MEMORIZATION_ANALYSIS.md` | nearest-training-song search over 8 representations |
| `ANNOTATION_NOISE.md` | full pseudo-labelled test set vs the human-checked clean subset |
| `LYRIC_FAILURES.md` | cramming, omission and the history of attacks on them |
| `FAILURE_TAXONOMY.md` | automatic multi-label failure tags with examples |
| `EDIT_RERENDER.md` | edit → re-render demonstrations through FastSinger + MuseControlLite |
| `experiment_registry.json` | every experiment: checkpoint, config, decoding, N, paths, comparability, caveats |
| `COMPUTE_LEDGER.csv` | every Slurm job of this round with GPU-hours |
| `tables/` | CSV + Markdown + LaTeX for every table (Tables 1-8 and appendix tables) |
| `figures/` | PDF + PNG for Figures 1-6 and appendix figures |
| `data/` | per-sample / per-song numbers behind every table (ids and numbers only — no lyrics) |
| `configs/` | frozen protocol JSON and song-id lists |
| `job_logs/` | Slurm stdout of every job, `SUBMISSIONS.txt` |
| `human_annotation_package/` | a 100-song re-annotation package (instructions, schema, UI, rescoring); **no human labels yet** |
| `listening_study/` | a blinded, counterbalanced control-oriented listening study; **no responses yet** |
| `edit_rerender_demo/` | per-demo metadata and verification (scores/audio are git-ignored) |

Lyric-bearing material (generations, scores, audio, annotation materials) is git-ignored by
design; it lives under `experiments/paper_final/` and the `materials/`, `scores/`, `audio/`
subfolders and is regenerated by the scripts.

## Reproduce

```bash
cd /mmfs1/gscratch/scrubbed/pingw220/music_acc/Qwen-ABC && source scripts/env.sh
python -m pytest -q tests                                   # unit tests incl. tests/test_paper_eval.py
# 1. generation (resumable; any subset of shards can be re-submitted)
for m in qwen_e3b qwen_e1 qwen_e1long qwen_e0 mupt; do MODEL=$m SUITES=bon NSHARDS=2 sbatch --array=0-1 scripts/paper_final/gen.sbatch; done
MODEL=qwen_e3b SUITES="replay interventions ood" NSHARDS=6 sbatch --array=0-5 scripts/paper_final/gen.sbatch
for m in qwen_e1 qwen_e0; do MODEL=$m SUITES=ood sbatch scripts/paper_final/gen.sbatch; done
MODEL=mupt SUITES=interventions CONDITIONS=bars_m4,bars_p4,label_bridge,key_p5,tempo_x1.25,lyrics_all NSHARDS=6 sbatch --array=0-5 scripts/paper_final/gen.sbatch
MODEL=mupt SUITES=ood CONDITIONS=ood_chorus_first,ood_long20,ood_sections_p3,ood_tempo sbatch scripts/paper_final/gen.sbatch
python -m paper_eval.midi_llm tasks && NSHARDS=6 sbatch --array=0-5 scripts/paper_final/midi_llm_shard.sbatch
python -m paper_eval.midi_llm convert
# 2. analyses (CPU)
python -m paper_eval.decoding
python -m paper_eval.ess
python -m paper_eval.intervention_analysis --model qwen_e3b && python -m paper_eval.intervention_analysis --model mupt \
  && python -m paper_eval.intervention_analysis --model midi_llm
python -m paper_eval.intervention_report --tag qwen_e3b --tag mupt --tag midi_llm
python -m paper_eval.tone_melody
python -m paper_eval.ood_analysis
python -m paper_eval.musicality
python -m paper_eval.annotation_noise
python -m paper_eval.failures
python -m paper_eval.main_tables
sbatch scripts/paper_final/memorization.sbatch              # see MEMORIZATION_ANALYSIS.md
python -m paper_eval.figures
python -m paper_eval.registry && python -m paper_eval.ledger
```
